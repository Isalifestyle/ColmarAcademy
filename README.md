# 🎓 ColmarAcademy — First HTML & CSS Website

**ColmarAcademy** is a responsive, static website modeled after a fictional educational institution, built entirely with **HTML** and **CSS**. This was my **first complete web project**, created as part of a Codecademy curriculum challenge.

It serves as a mock educational site for "Colmar Academy", showcasing a homepage, course offerings, campus details, and more—built to solidify foundational web development skills.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible structure  
- **CSS3** — Clean layout, styling, and responsiveness  
- **No JavaScript** — Focused on static frontend design only  

---

## 📂 Features

- 🎨 Fully responsive layout using flexbox and media queries  
- 🏫 Homepage showcasing courses, mission, and campus details  
- 📱 Mobile and tablet-friendly design  
- 🚫 No frameworks or libraries — just raw HTML & CSS  
- 🎯 Perfect for learning and practicing basic frontend web dev skills
